# Architecture decision records

Architecture Decision Records (ADRs) preserve significant technical choices and
their reasoning.

## Creating a decision

1. Copy the structure used by an existing record.
2. Assign the next four-digit number.
3. Begin with `Proposed`; change it to `Accepted` after agreement.
4. If the choice changes later, create a new ADR and mark the old one `Superseded by
   ADR-NNNN`.

Do not use ADRs for routine implementation details that can be explained clearly in
code or a pull request.
