# Glossary

Status: Draft

| Term | Definition |
| --- | --- |
| User | An authenticated application account. A user is not automatically a player. |
| Player | A football participant represented by a player profile; the profile may be linked to a user account. |
| Team | A football organization with staff and a roster. |
| Team owner | Team-specific staff member with ultimate authority over that team. |
| Team manager | Team-specific staff member allowed to perform delegated team operations. |
| Captain | A player membership designation; it does not automatically grant application permissions. |
| System administrator | A user with platform-wide administrative authority. |
| Tournament administrator | A user allowed to manage tournament operations; the exact assignment scope remains to be decided. |
| Roster membership | The relationship between a player and a team for a period of time. |
| Match submission | A score submitted on behalf of one of the participating teams. |
| Published result | The authoritative score visible as the official match outcome. |
| Dispute | A state caused when participating teams submit conflicting results or an administrator flags a result. |
| Correction | An audited change to a previously published result. |
